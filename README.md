# 🎮 GameVault - Catálogo Estático de Videojuegos

> **Proyecto Educativo para 2.º de Sistemas Microinformáticos y Redes (SMR)**

GameVault es una aplicación web estática para explorar, buscar y filtrar videojuegos en tiempo real. Ha sido desarrollada utilizando exclusivamente tecnologías web estándar sin dependencias de frameworks ni librerías externas.

---

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructura semántica completa.
- **CSS3:** Estilos avanzados con Flexbox, CSS Grid, variables CSS, efectos neón/gaming y animaciones.
- **JavaScript (Vanilla JS):** Renderizado dinámico de tarjetas, buscador interactivo en tiempo real, filtros combinados, ordenación y ventana modal.

## 🚀 Cómo ejecutar el proyecto en VS Code

1. Extrae este archivo ZIP en tu ordenador.
2. Abre **Visual Studio Code**.
3. Ve a `Archivo > Abrir carpeta...` y selecciona la carpeta `catalogo-videojuegos`.
4. Instala la extensión **Live Server** en VS Code.
5. Haz clic derecho sobre `index.html` y selecciona **Open with Live Server**.

---

## 🌐 Cómo desplegar en GitHub y Vercel

1. **GitHub:**
   - Entra en [GitHub.com](https://github.com) y crea un nuevo repositorio llamado `catalogo-videojuegos`.
   - Selecciona **Upload files** y sube todos los archivos de este proyecto.
   - Haz clic en **Commit changes**.

2. **Vercel:**
   - Inicia sesión en [Vercel.com](https://vercel.com) con tu cuenta de GitHub.
   - Haz clic en **Add New... > Project**.
   - Importa el repositorio `catalogo-videojuegos`.
   - Pulsa **Deploy**. ¡Tu web estará online en segundos!

---

## 🔄 Cómo actualizar la web en el futuro

Cuando modifiques el código en VS Code:
1. Sube los archivos modificados a tu repositorio en GitHub web (o mediante Git).
2. **Vercel detectará los cambios automáticamente** y actualizará la web desplegada sin que tengas que hacer nada más.
